FONTLOG for Noisy Mono
======================

Noisy Mono is an independently maintained Modified Version of Ioskeley Mono,
which is itself a custom build of Iosevka.

2026-07-24 — Release pipeline hardening
----------------------------------------

- Updated the generated families and showcase webfonts to Iosevka 34.7.0.
- Added a semantics-checked TrueType normalization pass before hinting. This
  canonicalizes two compact `glyf` records that FreeType rejects while proving
  that glyph order, cmap entries, outlines, and horizontal metrics are
  unchanged.
- Added complete local validation for all 180 hinted and unhinted desktop
  faces, 120 full-glyph webfonts, 180 Nerd Font faces, and all eight release
  archives.
- Made release archive creation deterministic and shared the same build,
  patching, packaging, and validation scripts between local preflight and
  GitHub Actions.

2026-07-23 — Initial Noisy Mono fork
------------------------------------

- Renamed the project, installed font families, build plans, artifacts, CSS,
  website, and release workflow to Noisy Mono.
- Pinned stable Iosevka, Nerd Fonts, and FontTools versions for reproducible
  releases.
- Added curated, feature-preserving WOFF2 subsets and retained a separate
  full-glyph web archive.
- Changed the Term family to strict Fontconfig-compatible spacing and enabled
  exported glyph names for Kitty programming ligatures.
- Patched Nerd Font variants in single-cell Mono mode and validated their
  fixed-pitch metadata.
- Documented the existing OpenType slashed-zero feature.
